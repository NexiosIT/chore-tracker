# General Standards

Cross-cutting conventions that apply to all services — naming, git workflow, code style, testing patterns.

## What Goes Here

Standards that are not specific to a service type. Examples:
- Naming conventions (files, variables, functions)
- Git workflow and branching strategy
- Code style and formatting rules
- Testing patterns and coverage expectations

## Naming Convention

`STD-{NNN}-{kebab-name}.md` for promoted standards, `{descriptive-name}.md` for drafts.
