# API Standards

Conventions for API design — response envelopes, error formats, pagination, versioning, authentication patterns.

## What Goes Here

Standards that apply to backend and gateway services producing APIs. Examples:
- Response envelope pattern
- Error response format
- Pagination conventions
- API versioning strategy
- Authentication/authorization patterns

## Naming Convention

`STD-{NNN}-{kebab-name}.md` for promoted standards, `{descriptive-name}.md` for drafts.
